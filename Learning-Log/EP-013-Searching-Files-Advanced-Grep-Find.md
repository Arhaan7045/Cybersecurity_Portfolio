*Date:* 24 November 2026
*Topic:* Searching Files & Advanced grep/find

*Topics learned:*
- Locating files and directories with `find`.
- Searching by filename and file type.
- Searching by file size and modification time.
- Searching file contents with `grep`.
- Performing case-insensitive and recursive searches.
- Displaying line numbers and counting matching lines.
- Excluding matching lines.
- Using extended regular expressions.
- Combining `find` and `grep` with `-exec`.

- **Linux commands learned:** `find`, `find -name`, `find -iname`, `find -type`, `find -size`, `find -mtime`, `find -mmin`, `grep`, `grep -i`, `grep -r`, `grep -n`, `grep -c`, `grep -v`, `grep -E`, `find -exec`.

*Cybersecurity lesson:* Investigating Linux logs, locating suspicious files and identifying potentially unusual activity through file metadata and content searches.

*Key takeaway:* `find` locates files; `grep` searches their contents. Combining them makes investigations more efficient.
