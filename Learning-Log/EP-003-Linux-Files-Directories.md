*Topic:* Linux File & Directory Operations

*Topics learned:*
- Creating files and directories.
- Copying, moving and renaming files.
- Removing files and empty directories.
- Understanding the effect of file-operation commands.
- Preserving original evidence and analysing copies.
- **Linux commands learned:** `mkdir`, `touch`, `cp`, `mv`, `rm`, `rmdir`.

*Cybersecurity lesson:* During investigations, preserve original evidence and work on copies whenever possible. Organise collected files carefully and avoid accidental deletion or modification.

*Key takeaway:* Understand whether a command creates, copies, moves or deletes data before running it.
