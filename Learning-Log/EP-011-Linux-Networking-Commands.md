*Date:* 22 November 2026
*Topic:* Linux Networking Commands

*Topics learned:*
- Inspecting network interfaces and assigned IP addresses.
- Understanding the default gateway and routing table.
- Testing connectivity with ICMP.
- Checking hostname resolution and DNS responses.
- Inspecting listening TCP and UDP sockets.
- Checking HTTP response headers.
- **Linux commands learned:** `hostname -I`, `ip addr`, `ip route`, `ping`, `getent hosts`, `nslookup`, `dig`, `ss`, `curl`.

*Cybersecurity lesson:* Network commands help analysts inspect system connectivity, DNS resolution, listening services and web communication. A failed ping alone does not prove that a destination is offline.

*Key takeaway:* Use network evidence to understand how a system communicates, and avoid drawing conclusions from a single connectivity test.
